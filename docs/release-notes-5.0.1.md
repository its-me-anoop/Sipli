# What's New in Version 5.0.1

• Reduce Motion: looping decorations, bottle slosh, and onboarding transitions now stay still when you ask iOS to reduce motion.
• More reliable logging from widgets and Siri — drinks no longer risk being overwritten when the app and a widget write at the same time.
• Safer Siri replies if a log or undo can't complete.
• Trophy Room, weekly quests, and share cards from 5.0 are unchanged.
