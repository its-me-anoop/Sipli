# Insights TestFlight crash investigation

Reported: iPhone Duo, Premium enabled, immediate crash on entering analytics
(Insights), following the 6.0 (16) upload. Xcode Organizer refreshed Sipli crash points
on October 25 and returned no reports in the last 14 days.

The unmodified Release simulator passed repeated Insights visits and both
chart timeframes. Simulator explicitly disables FoundationModels, so this
does not establish device AI safety. An older October 22 simulator crash
was in FoundationModels, but is not evidence of this TestFlight crash.

Mitigation: remove automatic model prewarming, digest generation, and insight
generation when Insights appears. Render existing deterministic summaries
immediately. AI generation requires an explicit button press, with duplicate
generation guards. No subscription bypass or user-data changes. The suspected
entry trigger is isolated.

The subsequently supplied device report D95D7BFE-6FDB-4F14-9F06-CBB04797C34E
confirms Sipli 6.0 (16), iPhone19,4, iOS 27.1 (24A94425). Faulting thread 2
traps in Swift `_assertionFailure` with FoundationModels frames. The main
thread's UIKit layout frames are not the faulting stack. The report does not
identify the exact model request or assertion condition.

Added a conservative iOS 27.1 compatibility exclusion before model availability,
prewarming, and generation. All surfaces retain deterministic fallbacks, and
HydrationAIService reports AI unavailable on that release. The exclusion covers
27.1 patch releases pending device verification; allowing other versions through
this policy does not establish that their model runtime is free of the defect.

Release build and `DuoLayoutTests/testInsightsRepeatedNavigation` passed on
the Duo simulator (`/tmp/sipli-insights-on-demand-release.log`). This covers
three tab round trips and 7-/30-day chart switching. Premium device AI
generation and the original TestFlight crash are not verified by this test.
The mitigation has not been uploaded to TestFlight.

After adding the compatibility guard, Release build and all 9 WeeklyStatsTests
passed, including OS-policy and deterministic-digest tests
(`/tmp/sipli-model-compatibility-tests.log`). Unit testing uses
`ENABLE_TESTABILITY=YES` for the Release app module. `git diff --check` passed.
