# Sipli 6.2 (24) — Sipli Scan

Scan a labelled bottle or can with on-device Apple Intelligence, review the drink and package size, then choose All, Half or Custom and explicitly Log what you drank. Package size is never automatically treated as consumption. Unmarked glasses and uncertain sizes need an amount from you. Photos are not saved by Sipli and there is no cloud-model fallback. Manual logging remains available.

Coffee-coloured beverage icons and quick-log amounts now use a brighter warm accent in dark mode, with contrasting selected glyphs and save labels.
